# Hermes Contract

## Transport

V1 uses a local OpenAI Responses-compatible endpoint:

```text
POST /v1/responses
GET  /v1/models
GET  /health
GET  /diagnostics
```

Loopback is mandatory. Requests carrying trusted Hermes execution metadata also require a runtime bearer token generated by the launcher/daemon.

## Provider mode

Hermes integration should use its `codex_responses` provider mode whenever compatible. Do not invent a new protocol until compatibility tests prove necessary.

## Trusted metadata

Trusted metadata is transport data, not prompt content.

Required canonical fields:
- runtime = `hermes`
- session_id
- turn_id
- round_id
- request_id
- purpose
- context_epoch

Optional fields:
- task_id
- parent_session_id
- cwd
- workspace_roots
- platform
- shell
- permission_profile
- enabled_toolsets

## Tool contract

The exact tool definitions in the active Hermes model request form the capability allowlist for that turn.

A ChatGPT MCP request is accepted only when:
- capability token is active;
- logical turn is current;
- tool name matches an advertised tool;
- arguments satisfy the tool contract;
- call identity is not a conflicting replay.

The bridge converts accepted MCP tool requests into Responses `function_call` events.

Hermes must execute through its normal AIAgent/tool-dispatch path.

## Tool result contract

Hermes returns a stable call identifier plus `function_call_output`.

Rules:
- same call ID + same result replay => idempotent;
- same call ID + different result => conflict;
- output for retired/unknown call => reject;
- late result must never revive a retired turn.

## Cancellation

Cancellation propagates Hermes -> transport -> browser execution -> capability retirement -> pending broker waiters.

## Provider stickiness

Once a logical Hermes turn has submitted work to ChatGPT Web, every continuation round of that turn stays on the same provider/runtime until final, abort or fatal cleanup.

## Durable state

Hermes owns persistent session/context/memory. The bridge must not mutate Hermes durable history independently.
